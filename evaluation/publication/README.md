# Publication-safe numerical summary

summary.json is a compact copy of existing saved Phase3 tiny/base.en and Phase4 performance-only aggregate results, created for sharing source. Original result files were not rewritten and no inference was run. Word coverage is not boundary accuracy; verified human references remain required. Dataset audio, raw transcript records, local paths, model files, checkpoints and private human recordings are not distributed.

Original local sources:../results/phase3_tiny_full.json, ../results/phase3_base_full.json and ../results/phase4_whisperx/full_result.json. These are deliberately ignored, so those paths need not exist in a fresh application clone. The research source/protocol docs are historical; reproducing them requires separately prepared approved data/cache/provenance, not merely starting the app. Read the root README for the application setup and docs/PUBLICATION.md for verified publication checks.
